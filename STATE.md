## Entwicklungsablauf bis zur Ubuntu-Installation

Der Betreiber hat am 29. September entschieden, die weitere Anwendung zunächst vollständig auf diesem Windows-Entwicklungsrechner am GitHub-Repository zu entwickeln. Docker Compose stellt hier PostgreSQL, Redis, API, Worker und Web für echte lokale Integrations- und Browserprüfungen bereit. Modellantworten und noch nicht freigegebene externe Dienste werden mit kontrollierten Testdaten geprüft; diese Belege ersetzen keine späteren Live-Aufrufe. Für Codeprüfungen `npm run build --prefix web`, `python -m unittest discover -s tasks -p 'test_*.py' -v` und die passenden Backendtests ausführen. Bei Datenbank- oder Dienständerungen zusätzlich eine echte lokale Integrationsprüfung. Die UI unter `http://localhost:4177` gehört zu diesem Windows-Rechner.

Der Ubuntu-Rechner bleibt bis zur abschließenden Installation der Videofunktionen ausgeschaltet. Dann werden Repository, Laufzeittools, geschützte Konfiguration und Google-AI-Pro-Anmeldung **direkt dort** eingerichtet; SSH und öffentliche Erreichbarkeit sind für die erste Abnahme nicht nötig. Erst danach sind Antigravity/Keyring, Pexels-Medien, Videoerstellung und Browserwiedergabe auf Ubuntu live zu prüfen. Bis dahin bleiben entsprechende Aufgaben trotz fertig entwickeltem Code offen. Social-Media-Arbeit folgt gemäß Produktentscheidung erst nach der echten Videoabnahme. [Ubuntu-Vorbereitung](tasks/remote-script-worker.md).

- Idee → automatisches strukturiertes Skript über bestehendes Gemini-Pro-Abo via Antigravity CLI → Benutzerfreigabe → Videoproduktion → abspielbare Vorschau. **Codex ist kein Bestandteil der Laufzeit.**
