## Entwicklungsablauf und Installation

Die Entwicklung läuft derzeit auf dem Windows-Rechner am GitHub-Repository. Docker Compose stellt hier PostgreSQL, Redis, API, Worker und Web für echte lokale Integrations- und Browserprüfungen bereit. Modellantworten und noch nicht freigegebene externe Dienste werden mit kontrollierten Testdaten geprüft; diese Belege ersetzen keine Live-Aufrufe. Für Codeprüfungen `npm run build --prefix web`, `python -m unittest discover -s tasks -p 'test_*.py' -v` und die passenden Backendtests ausführen. Bei Datenbank- oder Dienständerungen zusätzlich eine echte lokale Integrationsprüfung. `http://localhost:4177` bezeichnet immer den gerade verwendeten Rechner.

Die fertige Anwendung soll auf jedem **unterstützten** Windows-, macOS- oder Linux-Rechner mit Docker Compose, Python 3.12, Antigravity CLI, passender Google-AI-Pro-Anmeldung, genügend Speicher und den späteren Medienwerkzeugen installierbar sein. Repository, Laufzeittools, private Konfiguration und Anmeldung werden auf dem gewählten Rechner eingerichtet. SSH und öffentliche Erreichbarkeit sind für lokale Nutzung nicht nötig. Eine Live-Abnahme auf einem vollständig eingerichteten Rechner umfasst Antigravity/Schlüsselspeicher, Pexels-Medien, Videoerstellung und Browserwiedergabe. Bis zum Nachweis bleiben entsprechende Aufgaben offen. Social-Media-Arbeit folgt nach echter Videoabnahme. [Installationsanleitung](tasks/install-on-computer.md).

- Idee → automatisches strukturiertes Skript über bestehendes Gemini-Pro-Abo via Antigravity CLI → Benutzerfreigabe → Videoproduktion → abspielbare Vorschau. **Codex ist kein Bestandteil der Laufzeit.**
